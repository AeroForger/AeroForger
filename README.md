## Main Projects

### AeroFyl

AeroFyl is a compiled programming language I am developing.

It uses a C-style syntax and is designed around explicit behavior, small binaries, predictable execution, and native compilation.

The compiler currently targets Linux x86-64 and includes its own lexer, parser, semantic analysis, HIR, IR, machine IR, and native backend.

### Sydrogen

Sydrogen is an earlier programming language and compiler project.

It includes a native x86-64 backend, a Cranelift backend, typed variables and functions, collections, imports, project files, and the Furnace command-line tool.

A lot of what I learned while developing Sydrogen influenced the design of AeroFyl.
